- `2021 → FTP transferencia de archivos.` 

- `22 → SSH administración remota segura.` 

- `23 → Telnet administración remota sin cifrado.` 

- `25 → SMTP envío de correo.` 

- `53 → DNS resolución de nombres de dominio.` 

- `80 → HTTP páginas web sin TLS.` 

- `110 → POP3 recepcióndescarga de correo.` 

- `443 → HTTPS páginas web mediante HTTP + TLS.` 

- `3306 → MySQL conexión a bases de datos MySQL.`
